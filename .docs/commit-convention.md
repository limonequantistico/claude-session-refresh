# Commit convention

Plain capitalized imperative sentence. No Conventional Commits prefix.

```
Move the schedule off GitHub and strip the buffer machinery
Fix the /usage verification, which was systematically confounded
Rename the skill from /start to /setup
```

Detected from history on 2026-09-04: 8 of 9 human commits use this form. The single
`feat:`-prefixed commit is an outlier from the same day, not a switch.

Automated commits from the refresh workflow use `log: <YYYY-MM-DD HH:MM>` and are not
subject to this.
